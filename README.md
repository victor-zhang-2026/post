# Post v1.0.0

Post 是一款 macOS 本地 Markdown 快速记录工具，Built with [Hammerspoon](https://www.hammerspoon.org/)。

## 使用

1. 安装 [Hammerspoon](https://github.com/Hammerspoon/hammerspoon/releases)。
2. 下载并解压 `Post-v1.0.0.zip`。
3. 双击 `Install Post.command` 完成安装。
4. 按 `⌥D` 打开 Post；首次使用时选择 Markdown 存储目录。

快捷键：

- `⌥D` 打开
- `⌘S` 保存
- `⌘W` 关闭

同一天的记录会写入同一个 Markdown 文件。后续还可以使用任意 Agent 工具分析、汇总和洞察这些本地 Markdown 内容。
